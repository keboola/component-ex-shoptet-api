Set the connection once and add one row per object you want to extract.

**Connection.** Choose the authentication method:

- **Private API token** — generated by the merchant in the e-shop administration under
  *Connections → Private API*, with read rights for the endpoint groups you need. Available
  on Shoptet Premium.
- **Addon OAuth token** — the permanent OAuth access token the addon received when it was
  installed, plus the e-shop's OAuth server URL from *Connections → API partner → Access to
  API*. Requires being a registered Shoptet API partner.

Use **Test connection** to verify the token before adding rows.

**Rows.** Each row extracts one object into a table of the same name. Nested data — order
items, product variants, document line items — is written to companion tables keyed back to
the parent record.

- *Incremental update* asks Shoptet only for records changed since the previous run (where
  the endpoint supports it) and upserts them by primary key. It never removes rows: for
  deletions either use *Full load*, or add a row for the matching change-feed object.
- *Optional sections* are parts of the response Shoptet only sends when asked (order notes,
  product images, …). Use the load button to see what the selected object supports.

Additional documentation is available at
[api.docs.shoptet.com](https://api.docs.shoptet.com/).
